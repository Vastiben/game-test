# Empire

Un jeu de gestion d'entreprise pour apprendre l'argent en jouant : lance ton commerce, fixe tes prix,
gère ton stock et ta trésorerie, et évite la faillite.

- Pas de pub, pas de paiement, pas de compte.
- Le temps n'avance que quand tu cliques.
- Ta partie reste sur ton appareil et le jeu marche aussi sans internet après une première visite.

**Installer sur iPhone** : ouvre le lien dans Safari, touche Partager, puis « Sur l'écran d'accueil ».
**Installer sur Android** : ouvre le lien dans Chrome, touche ⋮, puis « Ajouter à l'écran d'accueil ».

Ce dépôt ne contient que le jeu compilé. Tous droits réservés.
